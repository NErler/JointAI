# Get the node names of names of nodes and elements

Get the node names of names of nodes and elements

## Usage

``` r
get_node_name(x)
```

## Arguments

- x:

  a character vector with names of nodes or elements (e.g., `"beta"`,
  `"D_y_id[1,2]"`)

## Value

a character vector with the names without the index (e.g., `"beta"`,
`"D_y_id"`)
